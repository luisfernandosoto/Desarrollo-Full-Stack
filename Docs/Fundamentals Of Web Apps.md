### 0b. Fundamentals of Web Apps
- **HTTP GET**: Browser requests HTML, images, CSS
- **Traditional web applications**: Server generates HTML dynamically
- **Running logic in browser**: Fetch data with JavaScript, manipulate DOM
- **Event handlers & callback functions**: `onreadystatechange`, `XMLHttpRequest`
- **Document Object Model (DOM)**: HTML tree structure
- **Manipulating the document from console**: Create elements, append, view updates
- **CSS basics**: Classes, IDs, style rules
- **Loading JS pages**: Sequence of HTML, CSS, JS, JSON fetch
- **Forms & HTTP POST**: Submit data, server processes it, redirect
- **AJAX**: Fetch data asynchronously without reloading the page
- **Single-page app (SPA)**: Browser renders data, server receives JSON, no reload
- **JavaScript libraries**: Vanilla JS, jQuery, React, Backbone, Angular, VueJS
- **Full-stack web development**: Frontend + Backend + Database
- **JavaScript fatigue**: Rapid changes, multiple tools, asynchronous challenges
