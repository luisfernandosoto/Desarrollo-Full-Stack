### 0b. Fundamentos de las Aplicaciones Web

* **HTTP GET**: El navegador solicita HTML, imágenes, CSS
* **Aplicaciones web tradicionales**: El servidor genera HTML dinámicamente
* **Ejecutando lógica en el navegador**: Obtener datos con JavaScript, manipular el DOM
* **Manejadores de eventos y funciones de callback**: `onreadystatechange`, `XMLHttpRequest`
* **Document Object Model (DOM)**: Estructura en forma de árbol del HTML
* **Manipulación del documento desde la consola**: Crear elementos, agregarlos, ver actualizaciones
* **Conceptos básicos de CSS**: Clases, IDs, reglas de estilo
* **Carga de páginas con JS**: Secuencia de HTML, CSS, JS, obtención de JSON
* **Formularios y HTTP POST**: Enviar datos, el servidor los procesa, redirecciona
* **AJAX**: Obtener datos de manera asíncrona sin recargar la página
* **Aplicaciones de una sola página (SPA)**: El navegador renderiza los datos, el servidor recibe JSON, sin recarga
* **Librerías de JavaScript**: Vanilla JS, jQuery, React, Backbone, Angular, VueJS
* **Desarrollo web Full-Stack**: Frontend + Backend + Base de datos
* **Fatiga de JavaScript**: Cambios rápidos, múltiples herramientas, desafíos asíncronos
