# Full Stack Open – Parte 0: Información General

## Introducción
- Curso de **desarrollo web moderno** con JavaScript.
- Enfocado en **Single Page Applications (SPA)** con **React**.
- Servicios web **RESTful y GraphQL** con **Node.js**.
- También incluye **TypeScript**, **React Native**, **CI/CD**, **contenedores**, **bases de datos** y **depuración**.
- Curso **totalmente gratuito**; se puede obtener **certificado y créditos ECTS** de la Universidad de Helsinki.

## Requisitos previos
- Buenas habilidades de programación.
- Conocimientos básicos de **web y bases de datos**.
- Conocimiento básico de **Git**.
- Perseverancia y capacidad de **resolver problemas e investigar por cuenta propia**.
- No se requiere experiencia previa en JavaScript o temas del curso.
- Se recomienda al menos **100-200 horas de práctica** en programación.

## Material del curso
- Se debe leer **una parte a la vez y en orden**.
- Contiene **ejercicios** que construyen aplicaciones paso a paso.
- Código de ejemplo disponible en **GitHub**.
- Muchos ejercicios contribuyen a una **aplicación más grande**.

## Estructura y ritmo
- 14 partes (0-13), con Parte 0 como introducción.
- Avanzar a la siguiente parte solo después de **dominar la anterior**.
- Partes 1-4: ejercicios con asterisco (*) contribuyen a la nota final.
- Partes 5-13: no hay dependencia de ejercicios anteriores.
- Duración flexible: **15-20 horas promedio por parte**.

## Discord y ayuda
- Grupo oficial: [Unirse al Discord](https://study.cs.helsinki.fi/discord/join/fullstack)
- Preguntas deben ser **claras y específicas**, incluyendo:
  - Código relevante
  - Salida de consola
  - Capturas de red (si aplica)
  - Enlace a GitHub con código

## Cómo estudiar
1. Hacer los ejercicios y marcarlos como completados en el **sistema de envío**.
2. Para créditos universitarios:
   - Registrarse en el curso a través de **Open University**.
   - Guardar el **número de estudiante** en el sistema.
   - Realizar el **examen online**.
   - Marcar la parte o curso completado.
3. Cada parte requiere registro separado para los créditos.

## Envío de ejercicios
- A través de **GitHub** y el sistema de envío.
- Usar **nomenclatura clara** si se mezclan partes en un repositorio.
- Se detecta **plagio** y se aplican políticas de la Universidad de Helsinki.
- Para aplicaciones grandes, se puede enviar solo el código **final** de la parte.

## Examen del curso
- Cubrir **partes 1-5**.
- Duración: **120 minutos**.
- Se puede repetir **una semana después** si se falla.
- El examen **no afecta la nota final**, solo es requisito para créditos.

## Número de estudiante y certificado
- Número generado automáticamente al registrarse por primera vez.
- Se puede obtener vía:
  - Sisu (perfil universitario)
  - Email de confirmación de inscripción
  - Contactando a **Student Services**
- Certificado disponible tras completar ejercicios **sin necesidad de examen**.
- Transcripción oficial disponible tras registro de créditos.

## Información adicional
- No hay versiones anuales; curso abierto **todo el año**.
- Material actualizado periódicamente (versiones de bibliotecas, claridad de texto, etc.).
- Posibilidad de **expandir cursos previos** o hacer **proyecto Full Stack**.
- Participación en proyecto puede otorgar **entrevista laboral** si se completan máximo créditos.

## Recomendaciones técnicas
- Navegador recomendado: **Chrome** o **Firefox Developer Edition**.
- Instalar **Git**, **Node.js** y editor compatible (recomendado: **VS Code**).
- Node.js usado: partes 0-5 → v22.3.0, parte 10 → v20.11.0, resto → v18.13.0.
- **npm y npx** incluidos con Node.js.
- No usar editores simples como Nano, Notepad o Gedit.
