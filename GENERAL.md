# Curso Full Stack Open

## General
- Curso gratuito sobre desarrollo moderno de aplicaciones web con **JavaScript**.
- Enfocado en **Single Page Applications (SPA)** con **ReactJS** y APIs REST construidas con **Node.js**.
- Incluye sección sobre **GraphQL**, alternativa moderna a REST.
- Cubre:
  - Testing
  - Configuración y manejo de entornos
  - Uso de bases de datos para almacenamiento
- Certificado y créditos **ECTS de la Universidad de Helsinki** disponibles gratuitamente.
- Valor: 5-14 créditos (curso completo) + proyecto asociado de 1-10 créditos.
- Socios y colaboradores: Houston Inc, Terveystalo, Elisa, Unity Technologies, Konecranes.
- Se ofrecen **conferencias de invitados** de expertos de empresas asociadas.

## Requisitos
- Buenas habilidades de programación
- Conocimientos básicos de desarrollo web y bases de datos
- Conocimiento básico de **Git**
- Perseverancia y capacidad de resolución de problemas de manera independiente
